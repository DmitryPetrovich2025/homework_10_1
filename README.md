 Проект "Декоратор"

## Описание:

Проект "Декоратор" - это приложение на Python для увеличения возможности
использовании функции без ее изменения.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Dmitry Petrovich"/myblog.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```


## Использование:

1. Загрузите программу.
2. Используйте ваши функции для расширения их функционала. 
3. Вносите дополнительные опции в декоратор, расширяя его возможности. 


## Тестирование
1. Программа была протестирована с покрытием в 88 %.
2. Результат тестирования можно посмотреть в HTML-файле.
