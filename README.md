# Проект homework_10_1


## Описание :

Проект homework_10_1 - это приложение на Python
для реализации 2-х задач :
1. Выделение данных из списка по ключу и отображение их в новом списке.
2. Сортировка входных данных по дате и возвращение отсортированного списка
по убыванию.


## Установка:


1. Клонируйте репозиторий:
```
git clone https://github.com:DmitryPetrovich2025/homework_10_1
```
2. Установите зависимости:
```
pip install -r requirements.txt
```


## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Применяйте по назначению или как дополнение к своему проекту.
4. Предлагайте свои дополнения и способы решения.
